## Practica10
Nota primero se debre crear una base de datos, en nuestro caso la llamamos Normalizacion

i.e. ejecutar desde la terminal:

Despues accedes a la base de datos desde la terminal ejecutando:

psql Normalizacion

### Orden de ejecucion de los scripts
1. primero se debe ejecutar 'DDL.sql'
2. despues ejecutar 'DML.sql'    -- este se ejecuta una consulta a la vez
